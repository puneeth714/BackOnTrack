Page Replacement Algorithms (FIFO & LRU)
Frame simulation & Page Fault count calculation
10 Marks 2.0 hrs prep
# Prerequisite: Paging hardware: Logical Address = Page # (p) + Offset (d).
# Rule: In LRU, replace the page that has not been referenced for the longest period. In FIFO, replace oldest frame.
# Common Trap: Mention Belady's Anomaly for FIFO (more frames can lead to more faults) to get full theory marks.
