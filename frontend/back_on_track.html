Fundamental Concepts to Clear First

1.0h Total

Clear these 3 micro-concepts first so you don't get stuck during numericals:

1. Semaphore Token Analogy (20 mins)

wait() takes a token (sleeps if basket empty). signal() returns a token. Mutex = 1 token; Empty buffer = N tokens.

2. Need Vector Rule in Banker's (15 mins)

Need = Max - Allocation. If a process finishes, it returns ALL previously allocated resources back to Available.

3. Page Offset vs Frame Shelf (20 mins)

Offset never changes during translation. Only the Page # is swapped for Frame # from the Page Table.
